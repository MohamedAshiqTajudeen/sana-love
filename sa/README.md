# For Sana

A lightweight, standalone, scroll-controlled animated love story for Sana Marzooqa, from Ashiq. It uses vanilla HTML, CSS, and JavaScript. The garden, roses, moonlight, and petals are drawn in SVG/CSS; the discovered letters are layered paper scenes. No image or audio files are required.

## Run locally

Open `index.html` in a modern browser. There is no build step, server requirement, framework, or dependency installation. Google Fonts load when online; system serif and sans-serif fonts are used as fallbacks.

## Experience

Scroll through one continuous illustrated garden. A centralized animation-frame scroll renderer moves the camera and character, changes her expression, blooms roses, reveals messages, and opens three physical-looking letter scenes. The closing scene includes a replay link. On narrow screens, camera zoom is capped, letter typography scales down, and the experience remains vertical. Reduced-motion preferences disable decorative motion and petals and soften camera zoom while preserving the story.

The page has no navigation, autoplaying audio, backend, database, authentication, or build step. Open `index.html` in a modern browser. Google Fonts load when online; system serif and sans-serif fallbacks are included.

`assets/images/` and `assets/audio/` are reserved for optional local assets; none are needed by this version.
